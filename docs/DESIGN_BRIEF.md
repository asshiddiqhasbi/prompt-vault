# UI & UX Design Brief v1.0
## Proyek: PromptVault (AI Workflow & Prompt Manager)

---

### 1. Design Principles

1. **Hyper-Utility & Low Friction (Maksimal 2 Klik)**
2. **Contextual & Visual Clarity**
3. **Developer-Centric Dark Aesthetic (Slate/Zinc + Emerald Accent)**

---

### 2. Design Tokens

- **Background**: `#09090b` (zinc-950)
- **Surface**: `#18181b` (zinc-900)
- **Border**: `#27272a` (zinc-800)
- **Accent Primary**: `#10b981` (emerald-500)
- **Variable Highlight**: `#3b82f6` (blue-500)
- **Fonts**: `Inter` / `Geist Sans` (UI), `JetBrains Mono` / `Geist Mono` (Prompt & Code)

---

### 3. Screen Inventory

- **Dashboard Utama (`/`)**: Search Bar (`Ctrl+K`), Category Pills, Tag Cloud, Prompt Card Grid.
- **Modal Variable Filler (`UsePromptModal`)**: Form input dinamis untuk `{{var}}`.
- **Modal Add/Edit (`PromptEditorModal`)**: Form CRUD prompt.
- **Modal Backup (`ExportImportModal`)**: Export & Import JSON.
